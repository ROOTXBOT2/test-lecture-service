게임 규칙

  • 60초 안에 최대한 많은 패턴을 기억하고 따라하세요
  • 패턴 길이는 3에서 시작하여 라운드마다 1씩 증가합니다
  • 틀리면 같은 패턴을 다시 시도하며 0.5초 패널티가 있습니다
  • 틀리면 콤보가 초기화됩니다

점수 시스템

기본 점수 10 x 패턴 길이
콤보 배율 1.0 ~ 3.0x (콤보 x 0.1)
예시 패턴5 x 콤보10 = 100점

고득점 전략

  • 콤보를 유지하세요 — 콤보 20 이상이면 3.0x 배율로 점수가 3배가 됩니다. 한 번도 안 틀리는 게 핵심입니다.
  • 위치를 외우지 말고 경로를 외우세요 — 개별 셀 위치보다 "왼쪽 위 → 오른쪽 아래 → 가운데" 같은 이동 경로로 기억하면 더 쉽습니다.
  • 청킹(Chunking) — 긴 패턴은 3~4개씩 묶어서 기억하세요. "123-456-789" 같은 덩어리로 나누면 기억력이 크게 향상됩니다.
  • 리듬을 타세요 — 패턴이 보여지는 리듬에 맞춰 입력하면 근육 기억이 형성되어 정확도가 올라갑니다.
  • 시간 관리 — 초반에 실수 없이 콤보를 쌓은 뒤, 후반 고난이도에서 높은 배율로 대량 점수를 얻는 것이 이상적입니다.

난이도별 특징

쉬움 3x3

9칸 그리드. 패턴 기억 입문용. 빠른 클리어로 콤보를 쌓기 좋습니다.

보통 4x4

16칸 그리드. 표준 난이도. 밸런스 잡힌 점수를 노릴 수 있습니다.

어려움 5x5

25칸 그리드. 상급자용. 기본 점수가 높지만 실수 확률도 높습니다.

도파민 이펙트

  • 콤보 5+ — 화면이 보라색으로 글로우
  • 콤보 10+ — 화면 쉐이크 + 글로우
  • 빠른 정답 — "PERFECT!" 텍스트 등장
  • 아슬아슬 클리어 — 비네팅 연출
  • 오답 — 빨간 플래시

게임 소개

패턴 배틀은 사이먼 게임에서 영감받은 패턴 기억력 도전 게임입니다. 60초 안에 화면에 표시되는 색상 패턴을 기억하고 정확히 따라하세요. 라운드가 올라갈수록 패턴이 길어지며, 콤보를 유지하면 점수 배율이 최대 3배까지 올라갑니다.

일간 챌린지에서 전 세계 플레이어와 경쟁하고, 자신의 기록을 갱신해보세요!

자주 묻는 질문

점수는 어떻게 계산되나요?

기본 점수 = 10 x 패턴 길이. 여기에 콤보 배율(1.0~3.0x)이 곱해집니다. 콤보를 유지할수록 높은 점수를 얻습니다.

틀리면 어떻게 되나요?

0.5초 패널티 후 같은 패턴을 다시 시도합니다. 콤보는 0으로 초기화되지만 라운드는 유지됩니다.

일간 챌린지란?

매일 같은 패턴 시퀀스로 모든 플레이어가 경쟁합니다. 같은 날 같은 조건에서 누가 더 높은 점수를 받는지 겨루는 모드입니다.

난이도 차이는?

쉬움(3x3=9칸), 보통(4x4=16칸), 어려움(5x5=25칸)으로 그리드 크기가 달라집니다. 칸이 많을수록 기억하기 어렵지만 기본 점수도 높습니다.

데이터는 어디에 저장되나요?

플레이 기록은 브라우저 로컬 저장소에 보관됩니다. 랭킹 참여 시에만 서버에 점수가 전송됩니다. 개인정보는 수집하지 않습니다.

콤보 배율은 어디까지 올라가나요?

최대 3.0x입니다. 콤보 20회부터 최대 배율이 적용됩니다.
